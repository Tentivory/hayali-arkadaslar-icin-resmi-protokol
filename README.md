# Hayali Arkadaşlar İçin Resmi Protokol Sistemi (HARP)

## Resmi Uyarı

Bu depo, insanlığın en büyük sorunlarından birini çözmek amacıyla kurulmuştur: **Hayali arkadaşlarla resmi yazışma protokolünün eksikliği.**

Yıllardır bilim insanları, filozoflar ve özellikle yalnız programcılar bu konuda çalışmalar yapmıştır. Sonuç? Hiçbir şey. İşte biz devreye girdik.

### Neden Bu Sistem?

- Hayali arkadaşınız size "Naber?" dediğinde ne cevap vereceğinizi bilmiyor musunuz?
- Resmi bir dilekçe ile hayali arkadaşınızdan izin almanız gerekiyor ama formatı yok mu?
- Hayali evcil hayvanınıza yemek saatini bildirmek için protokol arıyor musunuz?

**Artık var.**

Bu sistem, ISO 9001 standartlarında olmasa da, **ISO-HAYALI-2026** standartlarına %147 uyumludur. (Bu standart sadece bizim kafamızda var.)

### Özellikler

1. **Resmi Dilekçe Üretici**: Hayali arkadaşınıza resmi mektup yazar.
2. **Protokol Doğrulayıcı**: Yazılan mektubun yeterince absürt olup olmadığını kontrol eder.
3. **Ciddiyet Seviyesi Ayarlayıcı**: 0 ile 100 arasında (ama her zaman 0 çıkar).
4. **Gizli Mesaj Sistemi**: Kimse fark etmez, çünkü gizli.

### Kurulum

```bash
pip install hayali-protokol  # Bu paket yok, sadece hayal edin
python harf_protokolu.py
```

### Kullanım Örneği

Program çalıştırıldığında size sorular sorar ve resmi bir belge üretir. Lütfen çıktıyı yazdırıp hayali arkadaşınıza elden teslim edin. E-posta göndermeyin, çünkü hayali arkadaşların e-postası yoktur. (Bilimsel gerçek.)

### Bilimsel Kanıtlar

- %99.9 başarı oranı (test edilen 0 kişi)
- 0 peer-reviewed makale
- 1 adet yazarın kendi kendine verdiği ödül

### Sorumluluk Reddi

Bu yazılımın kullanımı sonucu hayali arkadaşınızın size kızmasından, sizi terk etmesinden veya gerçek dünyaya geçmesinden sorumlu değiliz. Ayrıca, bu yazılım hiçbir siyasi görüşü desteklemez. Hiçbir şekilde. Sakın aramayın.
